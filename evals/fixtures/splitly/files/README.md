# Splitly

Split bills with friends. Snap a receipt, Splitly reads it with AI and splits it across your group.

Built with Next.js 14 (app router), Supabase (auth, db, storage), Stripe (Pro lifetime upgrade) and OpenAI (receipt parsing).

## Dev

```
cp .env.example .env.local
npm install
npm run dev
```

Run the SQL in `supabase/migrations` in the Supabase SQL editor.
